## 📖 Sobre o projeto

Este projeto é uma landing page de turismo que apresenta **Busan**, a segunda maior cidade da Coreia do Sul, com três destinos imperdíveis para os amantes de história:

1. **Templo Haedong Yonggungsa**
2. **Templo Beomeo-sa**
3. **Parque Yongdusan**

O objetivo foi **colocar em prática** o que aprendi no terceiro módulo do curso, transformando um layout em uma página completa, semântica e adaptada para diferentes tamanhos de tela.

🔗 **Desafio original:** [Desafio prático: Local Turístico (Rocketseat)](https://app.rocketseat.com.br/projects/desafio-pratico-local-turistico)

🎨 **Design no Figma:** [Ver layout do projeto](https://www.figma.com/community/file/1384542229391733447/local-turistico)

🚀 **Deploy:** _em breve_

## ✨ Funcionalidades

- 📱 Layout **responsivo** para desktop, tablet e smartphone
- 🧱 Estrutura HTML **semântica** (`header`, `main`, `section`, `article`)
- 🎨 Paleta de cores e largura do container centralizados em **variáveis CSS**
- 🔤 Tipografia com a fonte **Open Sans** (Google Fonts)
- 🖼️ Imagens fluidas com bordas arredondadas

---

## 🛠️ Tecnologias e conceitos aplicados

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura semântica e acessibilidade (`alt` nas imagens, `lang="pt-br"`) |
| **CSS3** | Estilização, variáveis (`:root`), reset e tipografia |
| **Media Queries** | Adaptação do layout para tablet e smartphone |
| **Google Fonts** | Fonte Open Sans com `preconnect` para carregamento mais rápido |

### Boas práticas utilizadas

- `box-sizing: border-box` e reset global de `margin` e `padding`
- `font-size: 62.5%` no `html`, para facilitar o uso de `rem` (1rem = 10px)
- Container centralizado com `max-width` e `margin: 0 auto`
- Imagens com `max-width: 100%` e `height: auto`
- Meta `viewport` para funcionar corretamente em celulares

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/local-turistico.git

# Entre na pasta
cd local-turistico
```

Depois é só abrir o `index.html` no navegador, ou usar a extensão **Live Server** no VS Code (botão direito no arquivo > _Open with Live Server_).

---

## 📱 Testando a responsividade

No navegador, abra as ferramentas de desenvolvedor e ative o modo de dispositivo:

- **Chrome / Edge:** `Cmd + Option + I` (Mac) ou `F12` (Windows), depois o ícone de dispositivo
- **Safari:** `Cmd + Control + R` (Modo de Design Responsivo)
